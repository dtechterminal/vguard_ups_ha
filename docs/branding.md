# Brand images

`custom_components/vguard_inverter/brand/` holds the V-Guard wordmark and kangaroo as the integration icon, cut from V-Guard's own logo (gold on black) and centred on a transparent square (256 px and 512 px). The tagline is left out. Home Assistant 2026.3 and newer show it directly from the integration, also without internet access. See the [Home Assistant announcement](https://contributors.home-assistant.io/blog/2026/02/24/brands-proxy-api/).

The V-Guard name and logo belong to V-Guard Industries. They identify the compatible products; this community integration is independent of V-Guard Industries. Brand artwork is not covered by this project's MIT code license.
